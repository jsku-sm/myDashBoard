# 🌱 구쌤의 수학 교실

Streamlit 기반 수업용 대시보드입니다. 공통수학1·공통수학2, 1-1~1-7을 지원합니다.

**[처음 설정과 사용 방법 → README_시작하기.md](README_시작하기.md)**

실행 파일: `streamlit_app.py` · 권장 Python: 3.12

전체 폴더를 올려야 실행됩니다. 운영 데이터는 별도의 **GitHub Private 저장소에 암호화**해 저장합니다.
실제 토큰·암호화키·학생 명렬은 이 코드 저장소에 올리지 않습니다.

```bash
pip install -r requirements.txt
python scripts/run_demo.py
```

위 명령은 **가상 계정만 있는 로컬 데모**입니다. 운영 설정은 한국어 안내서를 참고하세요.

검증 범위와 미검증 항목은 [TEST_REPORT.md](TEST_REPORT.md)를 확인하세요.
